# Luma Stay — Project Overview

## 1. Project Identity

**Project Name:** Luma Stay  
**Category:** Luxury Boutique Hotel Website  
**Project Type:** UI/UX Showcase Website  
**Technology Direction:** React + Vite + Modern CSS + Minimal Vanilla JavaScript

Luma Stay is a high-end editorial hotel website designed to demonstrate advanced frontend engineering, UI/UX design, responsive layouts, and motion design.

The website is a showcase experience and does not require a production booking backend.

## 2. Vision

Create a digital hotel experience that feels closer to a premium architecture and hospitality editorial publication than a conventional hotel booking website.

The interface should communicate:

- Luxury
- Calm
- Architecture
- Privacy
- Craftsmanship
- Hospitality
- Exclusivity
- Place and atmosphere

## 3. Design References

The visual quality should be inspired by high-end editorial and creative studio websites such as:

- Mersi Architecture
- Merlin Studio
- In Common With

The project must not directly copy their layouts, assets, branding, or content.

## 4. Primary Objective

Demonstrate professional frontend capability through:

- Advanced CSS layouts
- Editorial typography
- Art-directed photography
- Responsive design
- CSS-based animation
- Scroll-triggered interactions
- Micro-interactions
- Accessible interface design
- Performance-conscious media
- Production-quality code structure

## 5. Experience Principle

The experience should follow:

**Atmosphere → Story → Space → Experience → Reservation**

The interface should never feel like a generic hotel template.

## 6. Target Audience

- Hotel guests
- Design-conscious travelers
- Creative professionals
- Recruiters
- Trainers
- Managers
- Developers
- UI/UX reviewers

## 7. Success Criteria

The completed website should:

- Look professional on desktop and mobile.
- Maintain strong visual hierarchy.
- Use intentional whitespace.
- Have smooth but restrained motion.
- Avoid layout shifts.
- Maintain accessibility.
- Achieve strong Lighthouse results.
- Use reusable React components.
- Be deployable as a static frontend.
