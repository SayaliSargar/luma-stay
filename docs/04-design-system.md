# Luma Stay — Design System

## Color Tokens

--color-bg: #F3F0E9
--color-surface: #E8E3D9
--color-text: #1B1B19
--color-text-secondary: #62615C
--color-text-muted: #85837B
--color-border: #D3CEC3
--color-dark: #1B1B19
--color-light: #F7F5F0
--color-accent: #9A7B52

## Typography

Use an editorial serif for major display headings and a modern sans-serif for interface and body content.

## Layout

Desktop: 12-column Grid
Tablet: 8-column Grid
Mobile: 4-column conceptual Grid

## Motion

Use transform and opacity for primary animations.
Respect prefers-reduced-motion.

## Responsive

Use clamp() for fluid typography and responsive spacing.

## Progressive Enhancement

Use @supports for advanced CSS features such as scroll-driven animation.
