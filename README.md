# Luma Stay

An editorial luxury hotel website focused on premium visual design, storytelling, responsive layouts, and refined interactions.

## Project

Luma Stay is a UI showcase project designed to demonstrate modern frontend development and high-quality visual design.

## Design Direction

- Editorial luxury
- Architectural photography
- Warm neutral palette
- Serif and modern sans-serif typography
- Asymmetrical compositions
- Generous whitespace
- Subtle purposeful motion
- Responsive experience
